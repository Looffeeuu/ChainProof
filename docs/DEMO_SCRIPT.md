# ChainProof 答辩演示脚本

答辩每组 10 分钟：**7 分钟展示 + 3 分钟提问**。展示由「PPT 讲述约 4 分钟 + 现场演示约 3 分钟」组成；学生互评依据答辩时播放的**讲解视频**，视频需单独录制，能脱离现场独立看懂。

| 版本 | 用途 | 时长 | 本文位置 |
|---|---|---|---|
| 现场演示版 | 答辩时接在 PPT 第 10 页之后，由全书阅在本机操作 | ≤ 2:45 | 第 2 节 |
| 讲解视频版 | 学生互评、提交材料第 4 项 | 6–7 分钟 | 第 3 节 |

所有操作都走真实 Fabric 网络，不手工修改账本。

## 1. 演示前准备（答辩 / 录制前 20 分钟）

### 1.1 重置环境

```bash
cd ~/ChainProof/backend
npm run demo:reset          # 提示时输入 yes，约 3–5 分钟
curl http://127.0.0.1:3000/api/health
```

记下 seed 输出的两张证书 ID（`alice @ P001`、`bob @ P002`）。

### 1.2 启动前端（新终端）

```bash
cd ~/ChainProof/frontend
cat > .env.local <<'EOF'
VITE_REAL_APIS=*
VITE_API_TARGET=http://127.0.0.1:3000
VITE_DEMO_MEMBERS=alice,bob,charlie,dave
EOF
npm run dev
```

### 1.3 桌面与浏览器

- 浏览器打开 `http://localhost:5173/`，缩放 100%，窗口宽度 ≥ 1280；关闭系统通知，隐藏书签栏。
- 桌面放两个文件：
  - `答辩成果-v1.pdf`：要提交的成果文件（任意小文件即可）。
  - `答辩成果-v1-改.pdf`：复制上一个文件后随便改一个字节，用来演示篡改可被发现。
- **仅现场版**：提前以 alice 身份在页面上创建项目「答辩现场演示」，成员 alice、bob、charlie，现场直接从提交里程碑开始。
- 提前打开一个标签页：`/verify/CP-DEMO-NOT-FOUND`。

## 2. 现场演示版（≤ 2:45）

逐句讲稿见 [NARRATION.md](NARRATION.md) B 版。

| # | 时间 | 身份 | 操作 | 讲解要点 |
|---|---|---|---|---|
| 1 | 0:00–0:35 | alice | 进入「答辩现场演示」→ **提交里程碑**：标题「最终成果 v1」，选 `答辩成果-v1.pdf`，指出页面立刻算出的 SHA-256；比例 alice 50 / bob 30 / charlie 20 → **提交并存证** | 「浏览器先算一次哈希，后端再独立算一次，一致才写链。链上只存哈希。」 |
| 2 | 0:35–0:50 | alice | 打开刚提交的里程碑 | 「提交者自己没有确认按钮，这条规则写在链码里。」 |
| 3 | 0:50–1:35 | bob | 切到 bob：**下载原文件** → 拖入核对框显示「一致」→ 拖入 `答辩成果-v1-改.pdf` 显示不一致 → **确认这份声明** | 「确认人核对的是这一份文件。改一个字节，哈希就完全不同。」 |
| 4 | 1:35–1:55 | charlie | 切到 charlie：**确认这份声明** → 状态变为**链上已验证**，出现 txId | 「全部确认人通过才是 VERIFIED，任何一人拒绝就整条作废。」 |
| 5 | 1:55–2:30 | alice | 回到项目页看贡献面板 → **签发我的贡献证明** → **去验证这份证书**，显示「证书有效」 | 「证书引用里程碑和链上交易，外部的人不用登录就能核验。」 |
| 6 | 2:30–2:45 | 任意 | 切到 `/verify/CP-DEMO-NOT-FOUND` 标签页 | 「伪造的编号查不到，返回 NOT_FOUND。」→ 切回 PPT 第 11 页 |

> 时间不够时，第 6 步改为口头说明；第 1、3、4、5 步是核心闭环，不能省。

### 现场备用方案

| 情况 | 处理 |
|---|---|
| Fabric 起不来 / 后端 500 | 立即改放讲解视频第 2 部分（完整闭环） |
| 写链较慢（> 5 秒） | 边等边讲双哈希原理，不要重复点击 |
| 电脑整体故障 | 用另一台电脑播放讲解视频 |

## 3. 讲解视频版（6–7 分钟）

视频用于学生互评，按评分标准（美观 20、实用 30、完整 30、创新 20）组织。**边录边讲，后期只加字幕，不配音**；逐句讲稿见 [NARRATION.md](NARRATION.md) A 版，下表是各段概要。全书阅录屏并讲解，杨宇剪辑、加字幕和片头片尾。

| 部分 | 时间 | 画面 | 讲解词 | 对应评分 |
|---|---|---|---|---|
| 0 片头 | 0:00–0:10 | 标题卡：ChainProof · 团队成果与贡献可信存证平台 · ChainProof 组 | — | — |
| 1 为什么做 | 0:10–0:45 | PPT 第 2–3 页 | 「小组作业、竞赛、科研合作里，最难说清的是谁做了什么。贡献表能被改，聊天记录说明不了文件，外人也没法核实。ChainProof 把成果文件、贡献比例和其他成员的确认一起存到 Hyperledger Fabric 上，并生成任何人都能核验的贡献证明。」 | 实用度 |
| 2 界面总览 | 0:45–1:20 | 概览页 → 项目 P001：贡献面板、存证概况、时间线 → 切换暗色主题 → 缩窄窗口展示响应式 | 「概览页集中展示项目、已验证里程碑和我的证明。项目页里，贡献比例只统计全员确认过的里程碑；时间线上每条记录都能看到对应的链上交易。界面支持亮 / 暗两套主题，窄屏下自动调整布局。」 | 美观 |
| 3 完整闭环 | 1:20–4:30 | 按第 2 节 1–5 步操作，但从**创建项目**开始：alice 创建「答辩演示」并登记 alice、bob、charlie → 提交里程碑 → 提交者无确认入口 → bob 下载核验（含篡改文件）并确认 → charlie 确认 → VERIFIED → 贡献面板更新 → 签发证明 → 公开验证 | 每一步沿用第 2 节的讲解要点，并补充：「创建项目同样是一笔链上交易」「贡献统计用整数运算和最大余数法，所有背书节点结果一致，总和严格 100%」「证书页可以直接打印或存为 PDF」 | 完整性 |
| 4 异常与权限 | 4:30–5:20 | ① `/verify/CP-DEMO-NOT-FOUND` → NOT_FOUND ② 切到 dave（非成员）打开 `/milestones/M004`，没有下载按钮 ③ 切到 charlie 打开「答辩演示脚本（P003）」，签发按钮不可用，提示累计 0% ④ P001 时间线上的「已拒绝」里程碑 | 「伪造的证书编号查不到；不是项目成员拿不到原文件，后端直接拒绝；没有被确认贡献的人签不出证书；任何一位确认人拒绝，里程碑就作废，不计入统计。」 | 完整性 |
| 5 创新点 | 5:20–6:20 | PPT 创新点页，或逐条叠字幕 | 「第一，他人确认才算数：提交者不能给自己作证，而且规则写在链码里，绕过网页也跳不过去。第二，确认人下载原文件在本地核验，确认的是这一份文件。第三，统计全程整数运算，所有节点结果完全一致。第四，证明无需登录即可公开验证。第五，链上只存证据不存内容，兼顾可信和隐私。」 | 创新性 |
| 6 片尾 | 6:20–6:40 | 团队页：全书阅（组长，后端 / 集成）、杨宇（前端 / 产品）、黄铭谦（区块链 / 智能合约）+ 仓库地址 | 「这是 ChainProof 组的作品，谢谢观看。」 | — |

### 录制要求

- 1920×1080，OBS 或 Windows「截图工具 → 录制」均可；总长 ≤ 7 分钟。
- 录制前执行一次 `npm run demo:reset`；第 3 部分从创建项目开始，**不要**提前创建「答辩演示」。
- 成片命名 `ChainProof-演示视频.mp4`，放到仓库根目录的 `delivery/`（已被 `.gitignore` 忽略，**不提交到 Git**）。
- 视频录制时顺手截取真实环境下的概览、项目详情、确认、证书、验证 5 张截图，替换 `docs/defense/screenshots/` 中的 Mock 截图。

## 5. 最终打包

```bash
bash scripts/package-delivery.sh            # 正式打包：视频、定稿打分缺一项就失败
bash scripts/package-delivery.sh --draft    # 预演：缺材料只警告
```

脚本先做敏感信息检查和材料齐全检查，然后按作业要求的 5 项材料整理目录，为三位成员各生成一个压缩包，命名为「组名-组长/组员-姓名-小程序名称」：

```text
dist-delivery/
├── ChainProof-组长-全书阅-ChainProof.zip
├── ChainProof-组员-杨宇-ChainProof.zip
└── ChainProof-组员-黄铭谦-ChainProof.zip
```
